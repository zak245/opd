        The pattern, so it can be reused for any screen

        Every case uses the same six parts. A new case only changes the screen model, the list of steps, and the rubric scores.

        Rail

        The steps, one rule each, in order. Done, current, and to come. Clicking any step jumps there.

        Stage

        The real screen, built from the real components, live at every step. The viewer can open the doors.

        Delta

        Things that move slide to their new place. Things that get hidden leave a ghost for a moment that names where they went.

        Score

        The nine-point review rubric, filled in as each rule lands. The improvement is a number, not a feeling.

        Evidence

        What moved, why, and the study behind it. One level down, behind a toggle. The page follows its own rules.

        Controls

        Back, next, play, compare. Arrow keys. A "you try" mode can be added later on the same model.
